Photonic Ring Resonator Simulation

Simulated a Silicon Nitride waveguide cross section for use in a full 3D simulation of a ring resonator geometry

I used GDSFactory and Tidy3D to design and simulate a complex 3D photonic ring resonator geometry used in an entangled frequency source photonic chip. I simulated a silicon nitride waveguide cross section called the Triplex Waveguide which is an asymmetric double strip waveguide. I was able to compute the single mode profile at 1.55 \(\mu\)m and also created the 2D ring resonator design. I ran into issues with tidy3d/GDSFactory as I was not able to extrude the waveguide cross section along the complex ring resonator geometry. There were also issues with the number of simulation credits I would require for a full ring simulation with high accuracy.

# t_b = 75 #nm

lambda_0 = 1.550 #um
n_sio2 = 1.45 #taken from TriPlex paper
n_sin = 1.98 ##taken from TriPlex paper

gds_path = "ADS_Cross_section.gds"

# Load a GDSII library from the file previously created
lib_loaded = gdstk.read_gds(gds_path)

# Create a cell dictionary with all the cells in the file
all_cells = {c.name: c for c in lib_loaded.cells}

print("Cell names: " + ", ".join(all_cells.keys()))
two_strip_loaded = all_cells["Unnamed_17"]

thickness = 10.0
SiN = td.material_library["Si3N4"]

medium_si3n4= td.Medium(permittivity=1.98**2) #SiO2 permittivity
structures = []
fig, ax = plt.subplots()
ax.grid()

for poly in two_strip_loaded.get_polygons():
    print(poly)
    #geom = td.PolySlab(poly, axis= 2, slab_bounds= (-thickness/2, thickness/2))
    geom = td.Geometry.from_gds(gds_cell= two_strip_loaded, axis= 2, slab_bounds=(-thickness/2, thickness/2), gds_layer=1)
    geom.plot(z=0.0, ax=ax)
    structures.append(td.Structure(geometry=geom, medium= medium_si3n4))

ax.set_xlabel("x ($\mu$m)")
ax.set_ylabel("y ($\mu$m)")
#now we construct the simulation

sim= td.Simulation(center= (0,0,0), size=(2,1, thickness+2), grid_spec= td.GridSpec.auto(wavelength=1.55),structures=structures, medium= td.Medium(permittivity=1.45**2), boundary_spec=td.BoundarySpec.all_sides(td.PML()), run_time= 5e-12)

#Lets compute the modes
from tidy3d.components.mode.simulation import ModeSolver
lambda_offset = .001 * lambda_0
freqs = np.round(np.divide(td.constants.C_0, np.linspace(lambda_0 - lambda_offset, lambda_0 + lambda_offset, 11)), 5)
mode_spec = td.ModeSpec(num_modes=1)
mode_solver = ModeSolver(simulation=sim, plane=td.Box(center=(0,0,0), size= (1.5,2, 0)), mode_spec=mode_spec, freqs= freqs)
mode_data=mode_solver.solve()
